## Behavior contract

Every server path runs under `DB_DRIVER=mysql`. Drizzle's MySQL builder diverges
from SQLite in four places that the port must abstract:

1. auto-increment id retrieval (`insertReturning` reads the driver `insertId`;
   MySQL has no `RETURNING`),
2. upsert (`ON DUPLICATE KEY UPDATE` vs `ON CONFLICT … DO UPDATE`),
3. insert-ignore (`ON CONFLICT DO NOTHING` has no MySQL builder equivalent;
   duplicate-key errno 1062 is swallowed),
4. raw writes (`tx.run` is SQLite-only; MySQL uses `execute`).

Sequence acquisition is atomic on MySQL through a `SELECT … FOR UPDATE`
transaction (DEV-01: plan §11.2 assumed `UPDATE … RETURNING`, which MySQL 8
does not support).
